¿QUIÉN FUE? — INTEGRATED WEBSITE

HOW TO RUN
1. Extract this folder.
2. Open the QuienFue_Integrated folder in VS Code.
3. Open index.html.
4. Right-click index.html and choose Open with Live Server, or open index.html in your browser.
5. Use the shared navigation to visit all five sections.

FILES
index.html        Homepage (Member 1)
suspects.html     Suspects
evidence.html     Evidence
puzzles.html      Spanish puzzles
reveal.html       Final reveal
Each page has its own CSS/JS files so styles do not overwrite each other.
Images used by the evidence page are in images/.
